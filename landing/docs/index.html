Installation & first setup

Download the ZIP from the GitHub releases page, unzip it and move Statefalse.app to Applications. On first launch, allow the app in System Settings if macOS asks.

Sign in with GitHub, select the workspace containing your repositories and choose the repository used for pull requests. Notifications and workflow status are then available from the menu bar.

Local Git authentication

Pull, fetch and push run locally on your Mac against origin. The PAT saved in Settings is never returned to the app for local Git; it remains backend-only for GitHub API operations.

Recommended: SSH

ssh-keygen -t ed25519 -C "you@example.com"
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
ssh -T git@github.com
git remote set-url origin git@github.com:OWNER/REPOSITORY.git

Alternative: HTTPS Keychain

git config --global credential.helper osxkeychain
git remote set-url origin https://github.com/OWNER/REPOSITORY.git

GitHub, OAuth & webhooks

OAuth signs you into Statefalse and authorizes the backend integration. The backend uses short-lived session tokens and refresh tokens. Configure a GitHub webhook for /api/webhook/github with a secret and workflow, check-suite, pull-request, review and comment events.

Webhook deliveries are verified with HMAC. If notifications stop, check delivery status and confirm that the configured secret matches the backend secret.

Administration

Production configuration belongs in environment variables, never in the repository. Keep OAuth secrets, JWT signing keys, webhook secrets and backend PATs private; rotate them if they have ever been exposed.

Database migrations run during backend startup. Before production deployment, create a backup, deploy the release, verify /health and keep the previous release available for rollback.

Security & privacy

Statefalse separates authentication, GitHub API access and local Git credentials. Repository files and Git credentials remain on the Mac. The backend receives only the data required by connected GitHub features and does not expose the stored PAT to the native client.

Releases & verification

Every macOS release includes a ZIP and SHA256SUMS. Verify the downloaded archive before installing:

shasum -a 256 -c SHA256SUMS
